# Этап 3 — Первый реальный READ-ONLY опрос Deye через Ebyte

**Статус:** подготовлен, физический опрос **не выполнен**.  
**Причина:** пользователь не подтвердил остановку клиента Home Assistant (другого Modbus-мастера к `192.168.25.15:502`). Без этого подключение запрещено требованиями этапа 3 (избежание коллизий Modbus-кадров на RS485).

## Параметры подключения (готово к использованию)

| Параметр | Значение |
|---|---|
| Хост (Ebyte NA111-E) | `192.168.25.15` |
| TCP порт | `502` |
| UART | `9600 8N1` |
| Режим | Modbus TCP → RTU, Simple |
| Function Code | 03 (Read Holding Registers только) |
| Таймаут | 2 с |
| Slave/Unit ID | 1 (предположение, требует подтверждения) |

## Предварительные проверки (завершены, без подключения к Modbus)

| Проверка | Результат |
|---|---|
| TCP порт `192.168.25.15:502` | OPEN |
| pymodbus версия | 3.16.2 (установлен локально) |
| `device_id` параметр | ACCEPTED (используется в драйвере) |
| `slave` параметр | REJECTED (не используется) |
| `ModbusTcpClient(host, port, timeout)` | Поддерживается |

## Необходимо перед подключением

1. **Подтверждение от пользователя:** клиент Home Assistant, опрашивающий `192.168.25.15:502`, остановлен.
2. Определение Slave ID (перебор 1–10, только FC 03, регистр 184 Battery SOC, если не подтверждён из конфигурации).
3. Запуск `readonly_diagnostic.py` — один цикл `read_all()`.
4. Закрытие соединения, завершение скрипта, отсутствие фоновых процессов.

## Карта регистров для опроса

См. `docs/modbus-register-map.md`. Читаются только подтверждённые регистры SG02LP1:
90, 91, 96–97, 108, 109–114, 167, 169, 183, 184, 186–188, 190, 191, 72–73, 74–75.
