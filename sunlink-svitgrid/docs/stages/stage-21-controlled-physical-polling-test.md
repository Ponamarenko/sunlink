## 3. Сравнение и стабильность

- Все три значения идентичны: `95 %` (`0x005F`) — стабильность в рамках короткого теста.
- Разброс времени ответа: 0.0356–0.0458 c (~10 мс) — без аномалий.
- Transaction ID увеличивался 1→2→3 и совпадал в запросе и ответе.
- Stage 19 дал `0x0063 = 99 %`; текущий тест — `95 %`. Разница объясняется
  изменением состояния батареи между Measurements, не противоречие протокола.
- **Сверка с дисплеем инвертора НЕ проводилась**: значение с дисплея в момент
  теста предоставлено не было. Значение не придумывалось, дополнительных
  запросов ради совпадения не делалось.

Три успешных чтения подтверждают повторяемость в рамках этого короткого теста,
но **не доказывают долговременную стабильность** постоянного polling.
