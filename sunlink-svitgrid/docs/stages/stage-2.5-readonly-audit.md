## 6. Найденные риски

1. **pymodbus API совместимость:** код использует `device_id=` (принято в 3.16.2). В `requirements.txt` проекта pin `pymodbus==3.6.2`, на сервере `192.168.25.20` pymodbus не установлен. Требуется проверка на целевой версии.
2. **Slave ID = 1** — предположение, требует подтверждения на устройстве.
3. **Уровень уверенности карты:** B для семьи SG02LP1; официальное подтверждение A для модели `…AM3` не получено.
4. **Агрессивное отключение при ошибке:** любая `isError()` ставит `connected = False`.
