## Ограничения Modbus Master

Через один шлюз NA111-E на шине RS485 в каждый момент времени должен работать **один активный Modbus Master**. Параллельный опрос драйвером SunLink и клиентом Home Assistant вызовет коллизии кадров/таймауты. Перед диагностическим опросом требуется подтверждение остановки другого мастера.

## Важные замечания

- Slave/Unit ID инвертора не подтверждён (в драйвере по умолчанию `1`).
- Официальный Modbus Register Map для модели `…AM3` не найден; карта основана на стороннем источнике уровня B.
- Все значения требуют сверки с экраном инвертора.
