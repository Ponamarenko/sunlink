#### **Проблема: Подключение к инвертору**
- **Симптом**: Ошибка подключения к 192.168.1.100:502
- **Причина**: Инвертор еще не подключен к сети
- **Решение**: Сервер работает в режиме ожидания подключения
- **Статус**: Ожидание реального оборудования

#### **Проблема: DeprecationWarning в FastAPI**
- **Симптом**: Предупреждение об устаревшем `@app.on_event`
- **Решение**: Игнорировать (не критично для работы)
- **План**: Обновить до lifespan event handlers в будущем

#### **API Эндпоинты:**
- `GET /` - Базовая информация
- `GET /status` - Статус системы
- `GET /registers` - Список регистров
- `POST /read` - Чтение регистров
- `POST /write` - Запись регистра
- `GET /live` - Live данные
- `POST /emergency-stop` - Аварийная остановка
- `POST /emergency-resume` - Возобновление
- `WebSocket /ws` - Real-time обновления

#### **Система безопасности:**
- Максимум 2 одновременные записи
- 5 секунд cooldown между операциями
- Валидация значений перед записью
- Emergency stop для быстрой остановки
