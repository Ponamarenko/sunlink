# Changelog

Всі зміни в проекті SunLink Mobile App документуються в цьому файлі.

## [1.0.6] - 2026-11-04

### 🚀 Нові можливості
- **Повністю перероблений інтерфейс** з Material Design 3
- **Система навігації** через бічне меню (drawer)
- **Підтримка світлої/темної теми**
- **Адаптивний розмір шрифта**
- **Покращена структура проекту**

### 🎨 Дизайн та інтерфейс
- Material Design 3 компоненти
- Професійна кольорова схема SvitGrid
- Плавні переходи та анімації
- Оптимізовані макети для різних екранів
- Покращена читабельність тексту

### 🔧 Технічні покращення
- Міграція на Kotlin для кращої підтримки Android
- Оновлені залежності (AndroidX, Material Components)
- Покращена архітектура з фрагментами
- Ефективне управління пам'яттю
- Оптимізована збірка APK

### 📱 Функціональність
- **Головний екран**: Інформація про додаток та версію
- **Налаштування підключення**: Конфігурація серверів
- **Налаштування вигляду**: Зміна теми та розміру шрифта
- **Про додаток**: Детальна інформація про SunLink

### 🔌 Ітеграція
- Підтримка SunPortal сервера
- WebSocket для реального часу
- REST API для отримання даних
- Локальне зберігання налаштувань

### 🛡️ Безпека
- Захищене зберігання налаштувань
- Валідація даних
- Обробка помилок з'єднання

### 📊 Документація
- Детальні README
- Інструкції з встановлення
- Опис архітектури
- API документація
- Політика безпеки
- Кодекс поведінки
- Інструкції для розробників

### 📦 Реліз
- **Розмір APK**: ~1.8 MB (release)
- **Версія**: 1.0.6
- **Мінімальна версія Android**: 5.0 (API level 21)
- **Цільова версія Android**: 14 (API level 34)

### 🏗️ Архітектура
- **Мова програмування**: Kotlin + Java
- **Платформа**: Android SDK 34
- **UI Framework**: Material Design 3
- **Архітектурний патерн**: MVVM з фрагментами
- **Зберігання**: SharedPreferences + SQLite

### 🔧 Залежності
- AndroidX Core KTX 1.12.0
- Material Components 1.11.0
- Navigation Components 2.7.5
- Lifecycle Components 2.6.2
- Fragment KTX 1.6.2

### Версіонування

Ми використовуємо [Semantic Versioning](https://semver.org/) для версіонування нашого додатку.

- **Major (X.0.0)**: Зміни, що порушують сумісність
- **Minor (X.Y.0)**: Нові функції, що не порушують сумісність
- **Patch (X.Y.Z)**: Виправлення помилок
