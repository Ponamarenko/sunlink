### Технічна інформація

#### Системні вимоги

- **Android 5.0+** (API level 21) або вище
- **Мінімум 100 MB** вільного місця
- **Інтернет-з'єднання** для онлайн-функцій
- **Рекомендовано** - Android 8.0+ для кращої продуктивності

#### Розмір APK

- **debug**: ~7.1 MB (з повною функціональністю)
- **release**: ~5.0 MB (з оптимізацією)
- **Архітектура**: Universal APK для всіх пристроїв

#### Архітектура

- **Мова програмування**: Kotlin
- **Платформа**: Android SDK 34
- **UI Framework**: Material Design 3 + Views
- **Архітектурний патерн**: MVVM з фрагментами
- **Зберігання**: SharedPreferences + ViewModel
- **Мережа**: Retrofit + WebSocket
- **Асинхронність**: Coroutines + LiveData

#### Залежності

- **AndroidX Core KTX 1.12.0** - основні компоненти
- **Material Components 1.11.0** - Material Design 3
- **Navigation Components 2.7.5** - навігація
- **Lifecycle Components 2.6.2** - життєвий цикл
- **Fragment KTX 1.6.2** - фрагменти
- **Retrofit 2.9.0** - мережеві запити
- **OkHttp 4.9.3** - HTTP клієнт
- **Gson 2.10.1** - JSON парсинг

### Встановлення та використання

#### Встановлення APK

1. Завантажте `app-debug.apk` з цього релізу
2. Перейдіть до завантажень на вашому пристрої
3. Натисніть на файл APK
4. Натисніть "Встановити"
5. Після встановлення запустіть додаток

#### Перше запуску

1. Відкрийте додаток SunLink
2. Дочекайтеся завантаження даних
3. Перевірте статус системи
4. Використовуйте бічне меню для навігації

#### Використання

- **Бічне меню** - швидка навігація між екранами
- **Головний дашборд** - повний огляд системи в реальному часі
- **Автоматичне оновлення** - дані оновлюються кожні 5 секунд
- **Статус система** - індикація онлайн/офлайн стану
- **Картки інформації** - потужність, напруга, батарея, статус, ефективність

### Проблеми та вирішення

#### Поширені проблеми

1. **Додаток не запускається**
   - Перевірте версію Android (5.0+)
   - Перевірте, чи встановлено необхідні дозволи
   - Перезавантажіть пристрій

2. **Проблеми з підключенням**
   - Додаток використовує mock дані, тому інтернет не обов'язковий
   - Перевірте статус системи в інтерфейсі
   - Дані оновлюються автоматично

3. **Проблеми з інтерфейсом**
   - Перезапустіть додаток
   - Оновіть тему
   - Перевірте розмір шрифта

#### Технічна підтримка

- Створіть issue на GitHub
- Надайте логи помилок
- Описуйте проблему детально
- Додайте скріншоти проблеми
