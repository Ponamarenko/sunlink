### Технічна інформація

#### Системні вимоги
- Android 5.0 (API level 21) або вище
- Мінімум 100 MB вільного місця
- Інтернет-з'єднання для онлайн-функцій

#### Розмір APK
- **debug**: ~2.5 MB
- **release**: ~1.8 MB (з ProGuard оптимізацією)

#### Архітектура
- **Мова програмування**: Kotlin + Java
- **Платформа**: Android SDK 34
- **UI Framework**: Material Design 3
- **Архітектурний патерн**: MVVM з фрагментами
- **Зберігання**: SharedPreferences + SQLite

#### Залежності
- AndroidX Core KTX 1.12.0
- Material Components 1.11.0
- Navigation Components 2.7.5
- Lifecycle Components 2.6.2
- Fragment KTX 1.6.2

### Встановлення та використання

#### Встановлення APK
1. Завантажте `sunlink-mobile-v1.0.8.apk` з релізу
2. Перейдіть до завантажень на вашому пристрої
3. Натисніть на файл APK
4. Натисніть "Встановити"
5. Після встановлення запустіть додаток

#### Перше запуску
1. Відкрийте додаток SunLink
2. Перейдіть до меню "Підключення"
3. Налаштуйте сервер SunPortal
4. Збережіть налаштування
5. Повторно запустіть додаток

#### Використання
- Використовуйте бічне меню для навігації
- Змінюйте тему у розділі "Вигляд"
- Налаштовуйте розмір шрифта
- Перевіряйте статус підключення

### Проблеми та вирішення

#### Поширені проблеми
1. **Додаток не запускається**
   - Перевірте версію Android (5.0+)
   - Перевірте, чи встановлено необхідні дозволи

2. **Проблеми з підключенням**
   - Перевірте інтернет-з'єднання
   - Перевірте налаштування сервера
   - Перевірте, чи сервер доступний

3. **Проблеми з інтерфейсом**
   - Перезапустіть додаток
   - Оновіть тему
   - Перевірте розмір шрифта

#### Технічна підтримка
- Створіть issue на GitHub
- Надайте логи помилок
- Описуйте проблему детально
