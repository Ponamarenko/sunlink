## 🚀 Швидкий старт

### 1. Встановлення додатку
```bash
# Копіювання APK на пристрій
adb install sunlink-mobile-v1.0.6.apk

# Або вручну:
# 1. Завантажте APK на пристрій
# 2. Відкрийте файл
# 3. Натисніть "Встановити"
```

### 2. Перша конфігурація
1. Запустіть додаток SunPortal
2. Перейдіть до меню → Підключення
3. Введіть адресу сервера: `http://sunlink.pp.ua:8000`
4. Збережіть налаштування
5. Перезапустіть додаток

### SunPortal Server
