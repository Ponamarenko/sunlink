## 🎯 Інструкції для створення GitHub Release:

### 1. Перейдіть до GitHub:
https://github.com/Ponamarenko/SunLink

### 2. Натисніть на "Releases"
### 3. Натисніть "Create a new release"
### 4. Виберіть тег: `v1.0.8`
### 5. Заповніть назву: `SunLink Mobile App v1.0.8`
### 6. Вставте вміст з файлу: `RELEASE_NOTES.md`
### 7. Завантажте всі файли з директорії `release-v1.0.7/`:
   - `sunlink-mobile-v1.0.8.apk`
   - `README.md`

   - `ARCHITECTURE.md`
