## 🚀 Створення релізу на GitHub

### Крок 1: Створення тега
```bash
# Перевірка поточного стану
git status
git log --oneline -5

# Створення тега для версії 1.0.6
git tag -a v1.0.6 -m "SunPortal Mobile App v1.0.6 - Complete release with Material Design 3"

# Відправка тега на GitHub
git push origin v1.0.6
```

### Крок 2: Створення релізу на GitHub
1. Перейдіть до репозиторію: https://github.com/Ponamarenko/SunPortal
2. Натисніть на "Releases"
3. Натисніть "Create a new release"
4. Виберіть тег `v1.0.6`
5. Заповніть форму:
   - **Title**: `SunPortal Mobile App v1.0.6`
   - **Description**: Вставте вміст RELEASE_NOTES.md
   - **Assets**: Завантажте всі файли з релізу

# SunPortal Mobile App v1.0.6

🎉 **SunPortal Mobile App v1.0.6** - Повністю перероблений мобільний додаток для моніторингу сонячної енергетики з Material Design 3!

## 🚀 Нові можливості

### 🎨 Повністю новий інтерфейс
- **Material Design 3** - Сучасний інтерфейс з найновішими компонентами
- **Система навігації** - Зручне бічне меню для швидкого доступу до функцій
- **Адаптивний дизайн** - Підтримка різних розмірів екранів
- **Плавні анімації** - Плавні переходи між екранами

### 🌓 Підтримка тем
- **Світла тема** - Зручна для використання при денному освітленні
- **Темна тема** - Зменшує навантаження на очі в темряві
- **Автоматична зміна** - Автоматична зміна теми залежно від системних налаштувань

### 🔧 Розширені налаштування
- **Розмір шрифта** - Три варіанти розміру тексту
- **Налаштування сервера** - Гнучка конфігурація SunPortal сервера
- **Локальне зберігання** - Збереження налаштувань на пристрої

### 🛡️ Покращена безпека
- **Захищене зберігання** - Шифроване зберігання конфіденційних даних
- **Валідація даних** - Перевірка вхідних даних для запобігання атак
- **HTTPS** - Захищена передача даних

## 📱 Функціональність

### Основні можливості
- **Real-time monitoring** - Моніторинг інвертерів в реальному часі
- **WebSocket integration** - Інтеграція з сервером через WebSocket
- **REST API support** - Підтримка REST API для отримання даних
- **Emergency stop** - Екстрена зупинка інвертера
- **Data refresh** - Ручне оновлення даних

### Інтерфейс додатку
- **Головний екран** - Інформація про додаток та версію
- **Підключення** - Налаштування сервера SunPortal
- **Вигляд** - Зміна теми та розміру шрифта
- **Про додаток** - Детальна інформація про SunPortal

## 🔌 Ітеграція

### SunPortal Server
- **URL**: `http://sunlink.pp.ua:8000`
- **WebSocket**: `ws://sunlink.pp.ua:8000/ws`
- **API endpoints**:
  - `/api/v1/status` - Статус сервера
  - `/api/v1/inverters` - Список інвертерів
  - `/api/v1/telemetry` - Телеметрія
  - `/api/v1/control` - Контроль інвертера

### Підтримувані інвертери
- Deye SUN-12K-SG02LP1-EU-AM3
- Deye SG02LP1 family
- Інші сумісні інвертери

## 📊 Технічні деталі

### Системні вимоги
- Android 5.0 (API level 21) або вище
- Мінімум 100 MB вільного місця
- Інтернет-з'єднання

### Розмір APK
- **Debug**: ~2.5 MB
- **Release**: ~1.8 MB

### Архітектура
- **Мова**: Kotlin + Java
- **Платформа**: Android SDK 34
- **UI**: Material Design 3
- **Архітектурний патерн**: MVVM з фрагментами

### Залежності
- AndroidX Core KTX 1.12.0
- Material Components 1.11.0
- Navigation Components 2.7.5
- Lifecycle Components 2.6.2
- Fragment KTX 1.6.2

## 📦 Встановлення

### Швидке встановлення
1. Завантажте APK файл з релізу
2. Перейдіть до папки завантажень на вашому пристрої
3. Натисніть на файл APK
4. Натисніть "Встановити"
5. Після встановлення запустіть додаток

### Конфігурація
1. Відкрийте додаток SunPortal
2. Перейдіть до меню → Підключення
3. Введіть адресу сервера: `http://sunlink.pp.ua:8000`
4. Натисніть "Зберегти"
5. Перезапустіть додаток
