# Встановлення SunLink Mobile App

## 📱 Встановлення додатку SunLink

### Системні вимоги
- Android 5.0 (API level 21) або вище
- Мінімум 100 MB вільного місця
- Інтернет-з'єднання для онлайн-функцій

---

## 🚀 Швидке встановлення

### 1. Завантаження APK
1. Перейдіть до релізу на GitHub
2. Завантажте файл `sunlink-mobile-v1.0.6.apk`
3. Збережіть файл на вашому пристрої

### 2. Встановлення додатку
1. Відкрийте папку завантажень
2. Натисніть на файл `sunlink-mobile-v1.0.6.apk`
3. Натисніть "Встановити"
4. Дочекайтеся завершення встановлення

### 3. Перше запуску
1. Знайдіть іконку SunLink на домашньому екрані
2. Натисніть для запуску
3. Дозвольте необхідні дозволи (якщо потрібно)

---

## 🔧 Налаштування

### 1. Підключення до SunPortal сервера
1. Відкрийте додаток SunLink
2. Натисніть на іконку меню (три горизонтальні лінії)
3. Оберіть "Підключення"
4. Введіть адресу сервера: `http://sunlink.pp.ua:8000`
5. Натисніть "Зберегти"

### 2. Налаштування вигляду
1. Відкрийте меню
2. Оберіть "Вигляд"
3. Оберіть тему (світла/темна)
4. Оберіть розмір шрифта
5. Натисніть "Застосувати"

### 3. Перевірка підключення
1. Після налаштування сервера перезапустіть додаток
2. Перевірте, чи з'явилася інформація про статус
3. Якщо є помилки - перевірте налаштування

## 🔍 Усунення проблем

### Додаток не запускається
1. Перевірте версію Android (повинна бути 5.0 або вище)
2. Перевірте, чи достатньо вільного місця
3. Спробуйте перезавантажити пристрій
4. Перевірте, чи не блокує додаток антивірус

### Проблеми з підключенням
1. Перевірте інтернет-з'єднання
2. Перевірте правильність адреси сервера
3. Перевірте, чи доступний сервер
4. Спробуйте змінити тип підключення

### Проблеми з інтерфейсом
1. Перезапустіть додаток
2. Змініть тему та розмір шрифта
3. Перевірте, чи не пошкоджені файли додатку
4. Очистіть кеш додатку

### Помилки при встановленні
1. Перевірте, чи дозволено встановлення з невідомих джерел
2. Перевірте, чи достатньо місця
3. Спробуйте завантажити APK ще раз
4. Використовуйте інший браузер для завантаження
