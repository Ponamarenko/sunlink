## 📡 Работающие API эндпоинты

- `GET /` - Базовая информация
- `GET /status` - Статус системы
- `GET /registers` - Список регистров (в полной версии)
- `POST /read` - Чтение регистров (в полной версии)
- `POST /write` - Запись регистра (в полной версии)
- `GET /live` - Live данные (в полной версии)
- `POST /emergency-stop` - Аварийная остановка (в полной версии)
- `POST /emergency-resume` - Возобновление (в полной версии)
- `WebSocket /ws` - Real-time обновления (в полной версии)

### 1. Проблемы с pymodbus
- **Проблема**: Ошибки при чтении 32-битных регистров
- **Статус**: Частично исправлено
- **Решение**: Требуется дополнительная тестирование с реальным оборудованием

### 2. Веб-интерфейс
- **Проблема**: Требует обновления для порта 8800
- **Статус**: Готов, но не протестирован
- **Решение**: Обновить пути в web_interface.html

### 3. Автозапуск
- **Проблема**: Требует systemd сервиса
- **Статус**: Сервис готов, но не настроен
- **Решение**: Настройка автозапуска
