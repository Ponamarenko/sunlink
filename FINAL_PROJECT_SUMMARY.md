## 🔧 **Как запустить**

### 1. **Сервер**
```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python deye_gateway.py

# Или через Docker
docker build -t deye-gateway .
docker run -p 8800:8800 deye-gateway
```

### 2. **Мобильное приложение**
```bash
# Импортировать в Android Studio
# Собрать APK
./gradlew assembleDebug
```

### 3. **Тестирование**
```bash
# Проверить сервер
python test_server_connection.py
```

- `GET /api/forecast` - Прогноз
- `POST /write` - Запись регистра
