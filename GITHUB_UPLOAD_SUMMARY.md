### 🎯 Installation Instructions

#### For Users
1. **Download APK**: 
   - From GitHub Release: https://github.com/Ponamarenko/sunlink/releases/download/v1.3.0/sunlink-mobile-v1.2.0.apk
   - Install on Android 15+ device
   - Open SunLink app
   - Connect to solar system

#### For Developers
1. **Clone Repository**:
   ```bash
   git clone https://github.com/Ponamarenko/sunlink.git
   cd sunlink
   ```

2. **Build Project**:
   ```bash
   ./gradlew build
   ```

3. **Run App**:
   ```bash
   ./gradlew installDebug
   ```
