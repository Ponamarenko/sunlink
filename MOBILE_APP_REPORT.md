### 2. **Технологический стек**

#### **Ядро приложения**
- **Kotlin** - Основной язык программирования
- **Jetpack Compose** - Современный UI фреймворк
- **Hilt** - Внедрение зависимостей
- **Coroutines** - Асинхронное программирование

#### **Сетевое взаимодействие**
- **Retrofit** - HTTP клиент
- **OkHttp** - HTTP клиент с WebSocket поддержкой
- **Gson** - JSON парсинг

#### **Архитектура**
- **MVVM** - Model-View-ViewModel
- **Clean Architecture** - Чистая архитектура
- **Repository Pattern** - Репозиторий паттерн

#### **База данных**
- **Room** - Локальная база данных (готова к использованию)

#### **Навигация**
- **Navigation Compose** - Навигация в Compose

### 3. **Основные экраны**

#### **Главный экран (MainScreen)**
- **Статус инвертора** - Онлайн/офлайн статус
- **Солнечные панели** - Мощность PV1, PV2, PV3
- **Аккумулятор** - SOC, напряжение, температура, мощность
- **Сеть и нагрузка** - Напряжение, частота, мощность
- **Энергетическая статистика** - Дневная генерация, покупка, продажа

#### **UI компоненты**
- **InverterStatusCard** - Карточка статуса инвертора
- **SolarPowerCard** - Карточка солнечных панелей с прогресс-барами
- **BatteryCard** - Карточка аккумулятора с индикаторами
- **GridLoadCard** - Карточка сети и нагрузки

### 4. **API интеграция**

#### **Серверная часть**
- **Базовый URL**: `http://192.168.25.117:8081`
- **API эндпоинты**:
  - `GET /api/status` - Статус системы
  - `GET /api/live` - Live данные
  - `GET /api/history` - Исторические данные
  - `GET /api/weather` - Погода
  - `GET /api/forecast` - Прогноз
  - `WebSocket /ws` - Real-time обновления

#### **Модель данных**
- **InverterData** - Основная модель данных инвертора
- **SystemStatus** - Статус системы
- **WebSocketMessage** - Сообщения WebSocket

### 5. **Функциональность**

#### **Real-time обновления**
- **WebSocket соединение** для мгновенных обновлений
- **Автоматическое переподключение** при обрыве
- **Кэширование данных** при отсутствии соединения

#### **Управление данными**
- **Repository** слой для абстракции данных
- **ViewModel** для управления состоянием UI
- **StateFlow** для реактивного обновления

#### **Обработка ошибок**
- **Глобальная обработка ошибок** сети
- **Локальное кэширование** при отсутствии соединения
- **Пользовательские уведомления** об ошибках
