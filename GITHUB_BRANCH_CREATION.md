# 🚀 Создание ветки deye-gateway в SunPortal репозитории

## 🔐 Требования для создания ветки

Для создания ветки в вашем репозитории SunPortal мне нужны:

1. **Доступ к вашему репозиторию** с правами записи
2. **Личные access token** GitHub с разрешением `repo`

## 📝 Инструкции для ручного создания ветки

### Вариант 1: Через GitHub Web Interface

1. **Зайдите на ваш репозиторий**:
   [https://github.com/Ponamarenko/SunPortal](https://github.com/Ponamarenko/SunPortal)

2. **Перейдите во вкладку "Branches"**

3. **Нажмите "New branch"**

4. **Заполните форму**:
   - **Branch name**: `deye-gateway`
   - **Source**: `master` (или `main`)
   - **Description**: `Deye Gateway integration for SunPortal`

5. **Нажмите "Create branch"**

### Вариант 2: Через GitHub CLI

Если у вас установлен GitHub CLI:

```bash
# Установите GitHub CLI (если не установлен)
# macOS: brew install gh
# Ubuntu: sudo apt install gh

# Авторизуйтесь
gh auth login

# Создайте ветку
gh repo create Ponamarenko/SunPortal --public --source= Ponamarenko/SunPortal
gh repo clone https://github.com/Ponamarenko/SunPortal.git
cd SunPortal
git checkout -b deye-gateway
git add .
git commit -m "Add Deye Gateway integration v1.0.0"
git push -u origin deye-gateway
```

### Вариант 3: Через SSH

```bash
# Клонируйте репозиторий
git clone git@github.com:Ponamarenko/SunPortal.git
cd SunPortal

# Создайте ветку
git checkout -b deye-gateway

# Добавьте файлы из архива
tar -xzf /path/to/sunportal-deye-integration.tar.gz
git add .
git commit -m "Add Deye Gateway integration v1.0.0"

# Отправьте на GitHub
git push -u origin deye-gateway
```

## 📦 Загрузка файлов в ветку

После создания ветки, добавьте файлы:

1. **Скачайте архив**:
   ```bash
   wget https://github.com/Ponamarenko/SunPortal/archive/refs/heads/deye-gateway.zip
   unzip deye-gateway.zip
   cp -r SunPortal-deye-gateway/* SunPortal/
   ```

2. **Или используйте готовые файлы** из `/root/opt/`:
   ```bash
   # Скопируйте файлы в вашу локальную копию SunPortal
   cp /root/opt/sunportal-deye-integration.tar.gz SunPortal/
   cp /root/opt/MANUAL_INTEGRATION_STEPS.md SunPortal/
   cp /root/opt/RELEASE_NOTES.md SunPortal/
   cp /root/opt/CREATE_GITHUB_RELEASE.md SunPortal/
   cp /root/opt/RELEASE_SUMMARY.md SunPortal/
   ```

3. **Сделайте коммит**:
   ```bash
   cd SunPortal
   git add .
   git commit -m "Add Deye Gateway integration v1.0.0

   - Added complete Deye Gateway server for SUN-12K-SG02LP1-EU-AM3 inverter
   - Added mobile app on Kotlin + Jetpack Compose with Material Design 3
   - Added REST API + WebSocket integration for real-time monitoring
   - Added web interface for manual control and configuration
   - Added Docker deployment support for easy scaling
   - Added comprehensive documentation and testing framework
   
   🤖 Generated by automation script"
   ```

4. **Отправьте на GitHub**:
   ```bash
   git push -u origin deye-gateway
   ```

## 🚀 Создание релиза

После создания ветки:

1. **Перейдите на GitHub** → SunPortal → Releases
2. **Нажмите "Create a new release"**
3. **Выберите ветку** `deye-gateway`
4. **Заполните release notes** из `RELEASE_NOTES.md`
5. **Загрузите APK** после сборки приложения

## 📱 Сборка мобильного приложения

```bash
cd mobile-app
./gradlew assembleDebug
# Загрузите app/build/outputs/apk/debug/app-debug.apk в релиз
```
